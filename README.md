# PhishER Workbench

Analyst-focused workbench for streamlining phishing investigation and triage with PhishER, Jira, and supporting security data.

## Overview

PhishER Workbench is intended to reduce repetitive analyst effort by integrating the existing Jira and PhishER workflow with structured data collection, validation, investigation, and evaluation.

The project is currently focused on validating the underlying Jira and PhishER integrations and building a reliable end-to-end workflow. AI-assisted investigation is planned after the conventional integration path has been proven.

## Current Status

The project is currently in technical discovery and feasibility validation.

Current priorities:

- Validate Jira webhook delivery.
- Retrieve and parse Jira cases through the API.
- Determine reliable Jira-to-PhishER correlation.
- Validate available PhishER API data.
- Build the initial non-LLM walking skeleton.

See [Project Overview](docs/project-overview.md) for project scope, architecture direction, design principles, and roadmap.
